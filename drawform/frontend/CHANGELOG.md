# Changelog

## 1.0.0 — 2026-09-11

- Initial public release of the approved VEYRA framed studio concept.
- Preserved application source, 18 media files and existing behaviour tests.
- Added portable setup, reference checksums, architecture/media guides, agent instructions and a complete reproduction prompt.
- Added optional LTX v2 image-to-video helper with local dry run and resumable jobs.
- Removed the direct Windows-only esbuild package declaration. The transitive platform package is selected by esbuild during installation.
- Included desktop/mobile reference screenshots and CI for Linux and Windows.

Known limitations are listed in docs/VERIFICATION.md.
