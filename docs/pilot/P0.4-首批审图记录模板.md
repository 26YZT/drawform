`GET /review/stats` 当前的 `total` 是审图操作条数，不是独立零件数。

规划人已确认 [12 项 A 方案](P0-12项A方案-执行口径.md)：同时报告审图分母与全部登记分母；手工版式改动归改后采用；主改动密度用人工纠错净处数；按同审核人五题起报。正常回答候选由引擎重出图不算人工纠错，回传动作本身不等于采用。

## 7. 本地记录与统计命令

在源码根 `drawform/` 执行。工具读取既有任务索引、图纸版本和审计，不修改它们。
同一台账的命令应由登记人串行执行；台账原子保存，已登记零件和已记录耗时不能通过命令静默覆盖。

先建立标为本地演练的空台账：

```sh
PYTHONPATH=src ../spike/.venv/bin/python -m drawform.eval.pilot init \
  --book /绝对路径/演练台账.json --title 本机演练 --source rehearsal
```

真实件台账用 `--source real`，并必须提供 `--retention-reference`，填写已经取得的留存确认依据。
填写该字段本身不构成留存许可；无许可时不要收集真实件。

工程师照常通过网页上传、回答问题、复核或回传图纸。登记一个任务：

```sh
PYTHONPATH=src ../spike/.venv/bin/python -m drawform.eval.pilot register \
  --book /绝对路径/演练台账.json --work /绝对路径/服务任务目录 \
  --job 实际任务ID --part 零件内部标识
```

同一任务重复登记不会多算一件。相同 STEP 指纹或重复零件标识会被拒绝，避免把重试算成新样本。
若零件有新的重试任务，先按本模板保留关联；不要伪造新零件标识绕过去重。

确实观察了逐题耗时后，记录当时首项和实测值：

```sh
PYTHONPATH=src ../spike/.venv/bin/python -m drawform.eval.pilot observe \
  --book /绝对路径/演练台账.json --work /绝对路径/服务任务目录 \
  --job 实际任务ID --question 实际问题ID --first-option 当时显示的首项ID \
  --elapsed-seconds 实测秒数 --observer 观察人姓名
```

这里只记录观察元数据；工程师选择哪个候选仍从服务答案审计读取。
没有观察就不执行此命令，不用自动请求耗时代替人的作答耗时。

生成可复核的 JSON 统计：

```sh
PYTHONPATH=src ../spike/.venv/bin/python -m drawform.eval.pilot report \
  --book /绝对路径/演练台账.json --work /绝对路径/服务任务目录 \
  > /绝对路径/演练统计.json
```

统计命令默认使用已确认的 5 秒阈值；也可显式传入 `--rapid-seconds 5` 复现同一口径。
报告会保留实际使用的 `threshold_seconds`；缺实测耗时时 `rapid_first.assessment` 为 `missing_observations`。
`all_unknown` 和 `all_rapid_first` 是供人工检查的观察信号，不能单凭一个小样本推断候选设计有错。

报告的 `first_pass` 按每件首次审图结论计算，后续接受不会抹去首次退回；未审核或未出图另列。
两种差异计数分别写在 `changes.from_draft` 与 `changes.adjacent_sum`，主指标 `selected_basis=human_verified_net` 使用人工核对记录；自动差异仅作诊断。
差异只覆盖既有 DXF 差异器能识别的对象，包含答案重出图，不等同于全部人工改动或全部缺陷。
审计损坏、STEP 指纹变化会使统计中止；缺失图纸会列为缺证据，不当作零改动。
演练报告固定标注机器生成语料和同源偏差，不能变成 30 件真实件基线。

## 8. 登记人工纠错依据

准备 JSON 记录，字段全部用于审图统计，不参与几何计算：

```json
{
  "reviewer": "实际核对人",
  "complete": true,
  "answer_changes_excluded": true,
  "items": [
    {
      "object_id": "本图内一条独立标注的核对标识",
      "net_changed": true,
      "versions": [1, 2],
      "reason": "实际修改原因",
      "evidence": "可复核的图面位置与审计引用"
    }
  ]
}
```

`versions` 必须是实际存在的人工回传版本号，不允许引用答案重出图版本；例子的 1、2 仅示意，不能照抄到真实台账。同一对象只有一条记录，多次人工修改列在 versions 中；最终回到原状则 net_changed 为 false。真正核对为零改动时 items=[]；没有核对时不登记。

```sh
PYTHONPATH=src ../spike/.venv/bin/python -m drawform.eval.pilot corrections \
  --book /绝对路径/台账.json --work /绝对路径/业务目录 \
  --job 实际任务ID --record /绝对路径/人工纠错记录.json
```

记录追加保存并绑定当前图纸 SHA-256；图纸改变后旧记录不会继续贡献计数，必须重新核对。净改动与累计改动分别按有当前有效人工记录的件数取分母，并列出缺证据件。

台账与业务文件一起备份，见 [PILOT_OPERATIONS.md](../../drawform/deploy/PILOT_OPERATIONS.md)。原有数据不删除，业务目录不再按任务数裁剪。
