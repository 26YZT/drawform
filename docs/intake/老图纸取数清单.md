# 老图纸取数清单（可直接转发）

用途：向技术部 / 图文档案 / PDM 管理员要一批**历史零件图**。这是一次性导出的请求，
不是请谁持续答题。第 1–8 节是转给对方看的；第 9 节是我方内部对照，不必转发。

---

## 1. 一句话要什么

> 想借 30–50 张**已经归档的单零件机械加工图**，要 CAD 源文件（DWG/DXF），不要扫描件。
> 先导 2 张给我看看格式能不能读，能读再批量导。图纸只在本机/内网用，不外发。

---

## 2. 数量与种类

- **总数**：30 张起，50 张更好。少于 20 张不足以分辨习惯差异。
- **两类各半**：
  - **回转体** 15–25 张：轴、销、套、法兰、盘、轮、齿轮坯、带台阶的回转件。
  - **简单棱柱件** 15–25 张：板类、块类、连接件、支座、安装底板、开槽/钻孔的方块件。
- **不要**这几类（变量太多，会把对照搞浑）：
  - 装配图、部件图（一张纸多个零件的）
  - 钣金展开图、焊接组合件图
  - 铸件/锻件毛坯图、热处理专用图
  - 模具件、夹具/工装图
  - 复杂曲面件（叶轮、壳体、机体大类）
- **图纸要是"最终批准版"**，不是过程稿或作废版（标题栏"标记/处数"区应为空，或状态栏为"归档/批准"）。

## 3. 抽样规则（避免拿到 30 张几乎一样的图）

| 规则 | 为什么 |
| --- | --- |
| **不要连续图号** | 同一系列派生图（一个图纸改尺寸派生出的 8 张）只取 1 张，其余等于重复样本。 |
| 跨 **≥3 个产品/项目** | 防止一个产品的制图习惯被当成集团标准。 |
| 跨 **≥2 位制图人** | 基准怎么选、尺寸怎么分组，个人习惯差别很大，这正是要看的。 |
| 跨 **≥2 个年份**（比如 2015–2019 与 2022–2025 各一半） | 看规范执行有没有随时间变过；如果有变，新图为准。 |
| 尽量含 **3–5 张"典型件"** | 那种新人入职会被拿来教的图，通常最能代表公认画法。 |
| 尽量含 **3–5 张"标注很少的简单件"** | 例如下图只标 4 个尺寸的垫块。我们需要知道简单件上老手会省略什么。 |

## 4. 文件格式（这一节是最关键的）

先说一条硬约束，它决定了优先级：**我方处理这批数据的机器上没有装任何 CAD，也没有安装权限**
（不能装 AutoCAD/中望/ODA 转换器），只能用开源库直接解析文件文本。开源库**读得了 DXF，读不了 DWG**。
所以：

按优先级，能给到上一层就不要给下一层：

1. **DXF —— 首选，请默认给这一种**
   - **ASCII 格式**（不是二进制 DXF，见 4.2），版本 **AutoCAD 2010 及以上（R2010/R2013/R2018）**。
     R2007 起 DXF 是 Unicode，中文不乱码；R2000/2004 是 GBK/ANSI，能读但容易出问题，实在只能给旧版请给 R2004 以上。
   - 所有主流 CAD 都有"另存为 / 导出 → DXF"：AutoCAD、中望 CAD、浩辰 CAD、CAXA 电子图板、
     SolidWorks/NX/Creo/CATIA 的工程图模块都可以。操作量和"打印成 PDF"差不多。
2. **原生 DWG** —— 只有在**同时**能给一份同名 DXF 时才有用；只给 DWG 的话第一轮打不开。
   如果图纸在系统里只有 DWG 且不便导 DXF，那就请**在有 CAD 的机器上跑一次批处理转换**
   （DWG → DXF R2018 ASCII，一条命令/一次右键批量另存即可），转换后的 DXF 给我们。这是一次性的，不用长期帮忙。
3. **PLM/CAD 系统里的工程图源文件**（`.prt/.drw/.slddrw/.cng/.exb` 等）
   - 请**同时导出 DXF**，并**连同 3D 模型一起给**（见第 5 节）。原生格式我方机器同样打不开。
4. **矢量 PDF**（从 CAD 直接"打印为 PDF"，文字可用鼠标选中）—— 退而求其次，能用于版式与文字统计。

**明确不能用的**：扫描件、拍照件、图片型 PDF（文字选不中）。这类只保留第 9 节标"△"的用途。

### 4.1 一个最容易踩的坑：尺寸不能是"炸开"的

老图经过批量转换、脱敏、覆盖盖章之后，经常变成下面这样：

- 尺寸线、尺寸界线、箭头变成普通直线与折线；
- 尺寸数字变成普通文字对象。

这样的图**打开来看很完整，但机器读不出"这是一个 Ø40 的直径尺寸"**，我们只能用于版式参照，
不能用于尺寸/基准配对。请在导出时确认：

- 选中一个尺寸，**属性面板里应显示为 DIMENSION（尺寸标注）对象**，而不是"直线 + 多行文字"；
- 标题栏文字应是普通文字实体或**块属性**；
- 公差应随尺寸一起存在（属性里能看到"上偏差/下偏差"或标注文字），不是另画的一条短线；
- 不要用"炸开/EXPLODE/扁平化/光栅化"类批处理，也不要盖红头章。

正因为这条只能实测，所以**先给 2 张试样**（1 张回转体 + 1 张棱柱件），我当天回一份"体检报告"，
确认能读到尺寸对象后再批量导。否则导完 50 张才发现全是炸开的，白费大家时间。
体检报告由一个脚本自动出（`research/check_intake.py`），逐张回答：能不能解析、DXF 版本、
有几个原生 DIMENSION、文字/块属性/矢量线各多少、有没有 ± 或配合代号、文字是否乱码、有没有代理对象，
最后给出这张图**能用于哪几类对照**（版式 / 尺寸与基准配对 / 图面可读性尺子 / 公差口径）。

重现命令：
```
cd drawform && PYTHONPATH=src ../spike/.venv/bin/python ../research/check_intake.py <图纸目录>
```

### 4.1.1 三个只在导出时才出现的坑

- **二进制 DXF**：AutoCAD"另存为 DXF"的对话框里有个 **"Binary DXF"复选框，必须不勾**。
  勾上之后文件扩展名还是 `.dxf`，但内容是二进制的，开源库读不了（报 "This is not a DXF file"）。
- **外部参照（XREF）**：如果图框和标题栏是外部参照挂进来的，导出时不带过来就是一张空图。
  请在导出前把参照**绑定（Bind）**进来，或直接给不含参照的图。
  我方这边表现为"块属性 0 个 + 文字很少"，会被退回——但退不回原因，所以请先按上面做。
- **代理对象/自定义对象**：某些国产 CAD 或插件生成的尺寸/粗糙度符号是"代理对象"，
  另存 DXF 时会变成 `ACAD_PROXY_ENTITY` 或被丢掉。试样脚本会数出代理对象个数，非零我们会退回要求换格式。

### 4.2 打包与命名（细节，照做能省一轮返工）

- **一张图纸 = 一个文件**。不要合并成一本多页 PDF，也不要一个 DWG 里塞多张图（图纸空间多布局可以，但请只用一个布局对应一个零件）。
- **文件名就是图号**（`12A.03.014.dwg`），不要用"图1/图2/最终版/新建文件夹"。有 3D 的同名不同扩展名。
- 单位 **mm**（默认都是，只是确认一下），比例不限（1:2、2:1 都行，标题栏里有写）。
- 图幅请**有搭配**：A1/A2 大图各几张 + A3/A4 小图几张。我们目前只在 A4/A3 上验证过排版，大图上的字高与尺寸线间距是不是同一套习惯，不知道。
- 一个 ZIP 交过来即可，不要按项目分多层压缩（解压脚本容易漏文件）。
- 如果 PDM 导出会带**封面页/目录页/签审单**，请去掉，只留图纸本体。

### 4.3 明确不要的处理

- 不要为了"看起来干净"先把图转成 PDF 或图片；
- 不要 EXPLODE / 炸开 / 扁平化 / 打散块；
- 不要盖红头章、不要加水印图层；
- 不要匿名化到把尺寸数字改成"XXX"（宁可少给几张，被抹掉数字的图对我们等于空样本）。

## 5. 最有价值的那一项：图纸 + 对应 3D 成对给

如果 PDM 里零件的 **3D 模型和历史图纸是挂在一起的**，请把它们成对导出：

- 2D：上面任一格式；
- 3D：**STEP（AP214 或 AP203，`.stp/.step`）** 优先，给不到就给原生 part 文件；
- 用同一个**图号**命名，例如 `12A.03.014.step` + `12A.03.014.dwg`。

为什么这个优先级最高：我们要验证的是"**给我这个零件，老手会怎么标**"。只有图纸没有模型，
我无法确定图上那个 Ø40 对应模型里哪个面；有模型才能自动比对（把模型投影到图纸上叠一叠，
轮廓重合就说明配对成立，这一步是自动的，不需要人工指认）。

**成对能给到多少算有用**：5 对就够起步；20 对能做出可信的比例统计。
没有模型的图纸仍然要，两者不要互相替代。

## 7. 顺手能要的两样东西（比图纸更容易给，价值高）

1. **企业制图规范 / 制图手册 / 校对标检查表**（Q/ 开头的企标、部门内部的"绘图须知"、
   培训 PPT、纸质手册的扫描件都算）—— 这是工程知识库唯一能直接用的文本语料。
   目前我们手上只有国标原文，没有**集团自己怎么用国标**这一层。
2. **常见"技术要求"条目文本**（图纸下方那 5–10 条：未注倒角、去毛刺、镀层、热处理、
   未注公差按 GB/T 1804-m 等）。可以是从图纸上抄下来的文字，不用整理成文档。

这两项即使图纸只拿到扫描件也仍然有效，请一并问一句。

## 9. 内部对照：每样东西解掉哪个死结（不转发）

| 用途 | 需要什么 | 现在卡在哪 |
| --- | --- | --- |
| **基准选择（最大单项漏标源）** | 矢量图纸 + 基准代号 | 现行代码里"尺寸从哪个面量起"是拿包围盒最小角凑的占位符。实测（2026-10-08 重现）全库漏标 141 条，其中线性尺寸池 87 条 = 62%，就是这一条。 |
| **该标哪些尺寸** | 矢量图纸（能读出 DIMENSION 与它挂在哪个特征上） | 现有 65 张参照图是**自动生成**的（cadsy），不是人画的。分数一直在跟机器习惯对齐，没跟车间对齐。 |
| **公差与 GD&T 的集团口径** | 带公差的尺寸 + 企业规范文本 | `parse_fcf` 结构解析已达 97.3%，但那是 ASME 数据；英文特征名 → GB/T 符号的对照表还没有（数表，需两份独立来源才能录）。生产上公差产出为 0 条。 |

| **手工工时基线** | 第 6 节工时列 | KR 里"替代制图劳动"无法量化，只能靠这一列。 |
| **RAG 语料** | 第 7 节文档 + 图纸技术要求文字 | 现在只有国标原文，缺集团内部经验文本 —— 这是 RAG 没落地的真正阻塞项，不是工时。 |

### 9.1 只有扫描件时的降级方案（要如实说，不能假装等价）

| 能做 | 不能做 |
| --- | --- |
| 标题栏版式与字段词汇、技术要求常用条目、视图数量与配置统计 | 基准选择/尺寸选择的量化对照（读不出"这条尺寸挂在哪个几何特征上"） |
