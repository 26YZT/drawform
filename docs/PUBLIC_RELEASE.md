## 发布范围

以现行 DrawForm 开发目录为来源，复制最新后端、React 前端、测试、运行时桥接源码、锁文件、量测脚本与设计/验证文档。使用新的 Git 根目录发布，避免将上级工作区的旧版副本、目录迁移记录和运行数据带入公开历史。

`SOURCE_SNAPSHOT.json` 记录原样复制文件的 SHA-256。README、本页、公开忽略规则、第三方汇总声明、首页截图及五孔板合成图为本次发布新增文件，不冒充此前冻结资产。

未包含：

- 用户工程图纸、试点工作区、任务数据库、审计记录、备份与交付包。
- `corpus/`、下载的 CAD/DXF 对照语料及没有独立公开来源说明的 DWG 验证样图。
- 本地令牌、证书、真实环境配置、虚拟环境、`node_modules` 与构建产物。
- 下载的参考项目、原版前端副本、Feishu 历史导出及旧版产品目录。

NIST 测试件保留公开来源说明；`drawform/out/seat.step` 是原项目已跟踪的程序化合成示例输入。前端素材、字体和许可声明一并保留。
