# 二段实心阶梯轴接入合同

2026-10-18，首包v2继续开发的有限扩展。沿用schema2、本地CAD独立运行时、唯一STEP→Drawing主链、现有澄清/模型版本/出图入口；不新增部署、认证、数据库表或外部provider。基线86源/130测试、1355 passed已核验冻结。

## 规格与来源

- kind=stepped_shaft；parameters精确为diameter_1_mm、length_1_mm、diameter_2_mm、length_2_mm；holes=[]。段1沿Z从0至L1，段2从L1至L1+L2；保留段号，不按粗细排序。所有尺寸有限且>0、≤1000；总长≤1000；两直径差须>1e-6，退化同径拒绝。同时支持D1>D2与D1<D2。
- 文字采用明确“二段阶梯轴/阶梯轴/stepped shaft”和第1/2段直径/长度角色；缺项只问对应字段，单位缺失确认mm。实心/solid或明确无孔作为来源事实，否则问shaft_solid，唯一选项solid（确认二段同轴实心、无孔）。禁止从未提孔自动推断实心；显式通孔/盲孔/螺纹/圆角/锥面/三段等仍拒绝。
- 文字原文SHA和NFKC span沿用原合同。图纸事实保留原生entity handle/layer或本地OCR page/bbox；全部备注须有消费记录，未知/冲突/未消费不转为可覆盖答案。四字段标签不可加入旧输入全局消费白名单；只在当前阶梯轴分支实际采用/核验。
- DXF限一个严格轴对齐、对称二阶轮廓（8个直线顶点），从左至右对应段1/2；必须有阶梯轴类型声明，不凭任意八点形状推断旋转实体。四值由真实原生轮廓读出；文本/原生DIMENSION若矛盾须阻断，不以用户覆盖。不能忽略其他实体、孔圆或独立轮廓。
- PDF/PNG/JPEG先以现有本地OCR读取明确二段类型和角色标注；至少2个可信角色值，其余可澄清。多零件/多有效页面、低置信数字、未知备注及未支持特征阻断。预览供采用前核对；不宣称任意图片轮廓理解。

## 出图与几何

- 固定建模源使用两个轴向相接实心圆柱融合；STEP单实体、闭合有效、无孔。双运行时分别冷读验证两外径、每段真实Z范围、肩面Z=L1/环面积、体积、材料/空气点，防止端序反转后仍仅靠包围盒/体积通过。
- 新增有界真实几何识别模块，不改变旧Shaft序列化/稳定ID。只对恰好两个同轴完整外圆柱＋三个正交轴平面、无其他特征的实心Z轴形体识别肩面。现有pipeline自动从STEP识别，避免额外出图profile在首次/恢复/重绘入口丢失；不新增Job指纹或持久化分支。
- 尺寸方案仅对该严格类型补齐长台阶Gap；原有20%通用规则保持。总长+一段轴向尺寸共同确定肩面，另一段由闭链推导，不重复全部实标。两外径、整体及有效肩面来源均落入同一Drawing，再由原四出口序列化。
- 肩面参考使用真实端面/肩缘点，并经实际FaceClassifier IN/ON核验；在Scheme保留有界支撑事实，place/gate核验world_points及投影。环面质心轴心不能作为肩面支撑。旧标准/规则/pipeline、旧测试和金标准不重写。

## 验收与分工

- 主真件D1=40,L1=30,D2=20,L2=40；反粗细/等长/直径与长度同数分别验证，防止借数值池通过。
- 文字缺L2→补40→模型→STEP→2D；实际DXF轮廓/实际PDF角色标注→必要澄清→模型→STEP→2D；版本修改保留父产物/原始来源，并验证新进程恢复。
- 新测试先红后绿，旧130测试资产不修改；独立原生DIMENSION测量及逐来源肩面核验，最终同一冻结源码全量回归。
- 根拥有规格、澄清控制、runtime/checker、几何识别与尺寸/gate集成；输入Agent仅text_intake/drawing_intake与新shaft_input/新测试；UI Agent仅page/UI_REFERENCE/本批DOM脚本；验收Agent仅新增轴出图/真实工作流测试和本批证据。实际CAD计算串行，不并发原生批次。
- 本轮不认领任意多段/复杂轴、配合/粗糙度/GD&T、任意自然语言/多视图或人工工程审图完成。
