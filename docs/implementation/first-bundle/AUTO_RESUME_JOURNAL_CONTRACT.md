# 自动续算与旧入口统一发布日志

2026-10-18 用户授权执行。沿用1551测试基线，旧测试与几何/标准/pipeline不修改。

- 标准本地/生产入口启用auto_resume；嵌入create_app可显式配置，默认保持旧调用兼容。能力接口披露实际开关。自动续算只用于已确认来源/规格、因服务中断而未完成的分析/建模；取消、超时、失败、损坏及超过持久上限不自动再试。不自动回答澄清、采用模型、修改项目HEAD或代审图。
- 同session/设计版本内独立attempt，不因执行重试分配新的模型版本。所有输入、规格、父版、纸幅与澄清依据冻结。每次新尝试在sessions/<sid>/attempts/<id>/，旧尝试全部保留；结果提交CAS匹配current_attempt_id，运行路径按当前目录重建，不复用归档绝对路径。
- 新模型/分析以model_attempt_id/analysis_attempt_id指向成功尝试；缺字段的旧记录按原路径读取。统一安全resolver覆盖下载、预览、父链、恢复、项目快照和包校验。
- 自动中断恢复最多3次，跨重启累计；恢复前重新核对source/spec/parent和运行协议。旧无attempt中断记录不猜测恢复；标准入口的新排队意图可恢复。硬退出后旧子进程仅按PID、进程出生身份及原工作目录证据确认后清理，旧attempt迟到结果不能提交。
- 旧写入口submit、submit_once、图前参考、图后答案、人工DXF回写和显式复核共用发布日志。五阶段prepared→captured→artifacts_committed→audit_committed→complete；request/basis与目标编号先持久化，精确审计意图先捕获，完成回执可幂等回放。
- 重启核验每阶段真实文件/索引/审计；完整捕获可补提交，计算未完成在新attempt续算。源、父版、冻结或槽位冲突立即阻断，不猜测覆盖或重号。人工accepted只能重放原始显式请求，机器恢复不产生工程签字。
- 旧无日志历史保持，不倒填虚构事件；只读接口不写日志。旧交付包在同锁捕获审计/文件并标明edition；仅DXF的新人工版不与旧PDF混称同版套件。
- 完整备份/恢复验证attempt及journal语义。统一项目包包含相关执行尝试和发布证据；保留所有原文件及历史包SHA。
- 必须验证真实控制进程强退→新进程自动续算→明确采用→真实STEP/2D→明确项目发布→统一包；另验证旧入口各阶段故障、重复请求、损坏/冻结阻断与新目录恢复。不得把synthetic状态测试当原生CAD/人工验收。
