# P0 剖视填充修复

本批修复上一批发现的剖面线缺半区问题。旧代码把边的拓扑枚举顺序当作轮廓连接顺序，也没有按边方向调整参数采样点，矩形因此被接成带有错误折返/连线的多边形。修复后矩形材料区完整填充，多孔板的孔洞留白。

最终全量 **870 passed + 1 xfailed(strict)，退出码 0，136.50 秒**；新增 **16** 个通过项，旧测试未改。3 组实际出图前后对照保留 **30 条约束、26 条可见原生尺寸**的原值、数量、测量端点及比例。实际人工制图审核数 **0**，未生产放行。

## 1. 唯一产品改动

`src/drawform/geometry/section.py` **+9 / −3 行**：按 wire 的连通顺序遍历边，结合当前 face 选择连接边；遇到反向边，反转其参数采样点后再拼接轮廓。外轮廓与孔洞仍使用既有奇偶裁剪，打印线距仍为原来的纸面 4 mm。

[OCCT 官方 WireExplorer 文档](https://occt3d.com/dev/doc/refman/html/class_b_rep_tools___wire_explorer.html)明确其按连通顺序遍历，face 参数用于选择连接边；[形状方向接口](https://occt3d.com/dev/doc/refman/html/class_topo_d_s___shape.html)与本机绑定签名也已核对。本机 `cadquery-ocp` 为 **8.0.1.1.0**，对应官方文档 **8.0.1**；没有升级依赖。

`pipeline.render_part` 仍是唯一渲染入口。实体、剖切位置、尺寸方案、问题候选、纸面比例和输出接口保持；本轮没有自动选择剖平面或新增页面功能。

表中覆盖估算是“剖面线长度 × 线距 / 材料面积”的数值积分，**不是真实件采纳率或制造公差**。矩形/三孔板使用独立解析面积；法兰使用原 STEP 薄片体积/厚度作为面积参考。法兰环壁比打印网格窄，按稀疏打印线积分会得到约 1.200475，不能以此判成重复填充。改用 **0.1 mm 诊断线距**得到 0.999585，打印线距和输出原文不变。

首次实际输出检查把这一稀疏积分误差判成失败，原 [after-outputs.log](../../drawform/out/p0-section-fill-20261014/after-outputs.log)与已生成四件套保留；只读复检改用适合薄环的诊断网格，未修改产品代码、测试或重画原图来抹掉记录。前后最终事实见 [before-checked-outputs.json](../../drawform/out/p0-section-fill-20261014/before-checked-outputs.json)、[after-checked-outputs.json](../../drawform/out/p0-section-fill-20261014/after-checked-outputs.json)。

3 件修复图共 **225 个材料采样点**由原 STEP 的实体分类器核对，均在材料内或其边界；分类容差 0.020001 mm 对应既有曲线离散误差，不是尺寸允许差。矩形和多孔板的 SVG 仅 **HATCH** 层变化，其他图层和全部文字相同；法兰 SVG 和 PDF 预览像素均未变，作为正常对照保留。

3 件共 26 条原生 DIMENSION 测量与公称值在 1e-6 mm 绝对误差内一致；26 条尺寸逐来源的原值、数量和测量端点严格保持。实际 DXF 视口映射与 SVG 剖面线端点误差均小于 0.002 mm。这些为技术比较容差。

6 张前后 PDF 均成功渲染且源字节未变，3 张修复图逐张 AI 观察；图面继续写“未经制图审核”，没有填写真实签字。大矩形的前后 PDF 都有两条 Poppler 字体类型/嵌入字体不匹配警告，渲染退出 0，其余四张无该警告。记录见 [visual-checks.json](../../drawform/out/p0-section-fill-20261014/visual-checks.json)；跨阅读器字体兼容及专业制图审核仍需现场证据。
