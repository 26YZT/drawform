# 首包v2：文字缺尺寸澄清与模型版本真实闭环

2026-10-18；按用户继续推进首包v2的开发授权执行。正式工程根为汽绘-drawform-vibecoding版。

文字输入现在可以缺少关键尺寸：系统保存原文，读取明确事实，只追问缺项；部分答案可保存并恢复，补齐后进入现有真实建模、版本、STEP导出与2D工程图流程。

## 用户可体验的变化

- “做一块长100毫米、宽60毫米的板，中间开一个直径20毫米的通孔”只问厚度；补8后得到100×60×8、中心Ø20通孔实体。
- 板件长/宽/厚、明确孔的直径和XY、垫圈内/外径、圆盘厚度缺失可逐项补充。孔XY允许负数或0；未明确孔配置时先选无孔或中心通孔，选中心孔后再问孔径。未明确文字单位时确认毫米，未明确编号孔坐标原点时确认板中心。
- 原始输入文字、规范化片段出处、已读事实、用户补充和模型修改差异分别显示；模型第二版继续保留第一版的文字及补充依据。
- 采用后导出原生B-rep STEP，调用既有DrawForm主链生成DXF/SVG/PDF/JSON；DXF为可测量的原生DIMENSION。修改孔径生成独立模型版本及Job，可切回旧模型、旧图纸。

## 代码与接口

| 文件 | 改动 |
| --- | --- |
| `drawform/src/drawform/workbench/text_intake.py` | 新增严格有限的部分文字解析、NFKC片段事实与动态问题；未知特征/冲突/非法数值直接拒绝。 |
| `drawform/src/drawform/workbench/clarifications.py` | 新增图纸/文字共享回答控制；来源核验、问题版本/依据、答案白名单、事务与请求去重。 |
| `modeling.py` | 两条完整旧解析均失败后才进入部分文字分析；等待时不排CAD队列，补齐后复用schema2简单零件建模。 |
| `drawing_workflow.py` / `api.py` | 既有answers端点委托共享控制；严格JSON拒绝重复键、过大或过深请求。原drawing basis序列化保持。 |
| `simple_spec.py` | 未确认显式孔原点禁止建模；原有几何/贯穿检查继续生效。 |
| `page.py` | 原文/规范化片段/补充展示、缺厚度示例、文字专用澄清与变体文案。 |

协议见[文字澄清合同](../implementation/first-bundle/TEXT_CLARIFICATION_CONTRACT.md)。继续使用`POST /api/workbench/v1/modeling/sessions/{sid}/answers`，body为basis_sha256、revision及当前qid→typed value的answers映射。没有增加自由代码、路径或外部provider。

原文SHA按原始UTF-8计算；span明确指向单独保存的normalized_text，原文与规范化摘要分开。问题清空前不生成STEP；问题清空后由spec_from_analysis核验再排队。已读尺寸不可通过answers覆盖；设计修改须进入既有revisions入口。
