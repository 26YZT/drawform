## 审查结论的复核

| 原结论或修改 | 复核结果与处理 |
|---|---|
| 孔、轴混用公差带代号 | 问题成立。现有候选生成修改方向正确：孔用已核对的大写代号，轴用小写代号，仍完整列出适用数表候选。但旧任务保存的混合候选还能绕过它；本轮在答案应用时再核对当前几何主体与已核对数表，拒绝错误代号，且不发布新图。 |
| 奇数孔 PCD 无法落位 | 问题成立。公共分布圆、点划线圆和纸面缩放修改可保留。但原回退分支按待验证的方案值生成端点，错误值也能“测量一致”；本轮先从孔圆心独立测出圆，再核对方案值，端点只取真实分布圆，错误值留给现有门禁拒绝。 |
| 沉孔阻断理由重复 | 已有去重修改正确。独立测试确认同一缺肩面事实仅报一次，不同直径/深度错误仍全部保留，判定仍为阻断。没有为“通过率”取消该门禁。 |
| 一般公差未覆盖就应强制阻断 | 不采纳。已有产品策略明确允许出图并给出未覆盖说明、待确认项与人工复核要求；已有相关测试保持。未自行新增阻断规则。 |
| 固定三视图等于“表达能力为零” | 表述过度。三视图与显式剖切已存在，尚缺的是自动选择视图和剖切位置。没有新增未经依据确认的自动决策。 |
| 自动初稿无专门公差，被概括为“精度全空” | 自动初稿的统计成立，但不代表整个产品没有公差输入回写能力；原报告本身也记录了选择 H7 的复现。当前已有问题卡、封闭候选、人的回答、公差回写及审计版本。本轮实测孔 H7、轴 h7 回写；没有因此宣称形位公差框格或粗糙度已实现。 |
| F2 77.5%、评测分母受限 | 原报告关于分母和同源偏差的提醒正确，不能把它读成完整图纸完成度。本轮重跑 F2 为 76.9%，recall 77.9%、precision 73.0%，旧数字不直接沿用；当前结果也不等于人工工程验收。 |
| 源码不存在任何 HTTP 出站 | 不能泛化到当前完整源码。运维模块已有显式配置的 HTTPS 健康探测；它不等于外部 AI 调用。本轮未做全产品网络封闭性验收。 |
| Google 字体白名单 | 没有据此认定发生过外传；但它违背当前资源全部本地提供的边界。本轮删除首页 CSP 中两个外部字体来源，浏览器实测字体加载正常，所测流程没有外域资源请求。 |

## 本轮继续修复

1. `service/answers.py`：历史候选不能覆盖当前孔轴类型与公差数表；错误回答整批不应用，不写新图。
2. `dimensioning/place.py`：PCD 从孔几何独立量出，与方案在 1e-6 mm 数值界内一致才落位，避免按错误值反造端点。此界是数值一致性界，不是制造公差。
3. `service/frontend.py`：移除外部 Google 字体 CSP 许可，保留本地静态资源与已有页面。
4. `research/measure_corpus_baseline.py`：落位覆盖按方案来源计数，单列图上实际标注条数；不把合法的合并标注误判为漏落位，并明确合成参照口径。
5. 新增独立回归文件 20 项。更新 10 个与前述行为冲突的旧测试函数：孔轴候选与候选上限按正确语义断言；8 项拒图测试改用真实双实体 STEP，继续检查拒图状态、原因、无文件、禁止采用/回写。没有删除、跳过、xfail 或关闭这些检查。
