# GEO-019：内部扩腔误标沉孔的修复与验证

批次：2026-10-15，P0.4 准备阶段的 T-28 技术修复、T-29 文档同步及 T-22 本机接入。本文记录机器验证，不代表实际制图审核或 T-30 签字。

## 结果与批准边界

原样本 `part_0047` 两端均经肩面转入小孔，中间的 Ø70 圆柱空腔被旧配对逻辑误当作沉孔，实际 PDF/SVG/DXF 中出现 `⌴⌀70` 和 `↧90`。本轮按 STEP 共享边连接关系识别两端内部扩腔；保留 Ø70 真实直径和原始圆柱长度事实，去掉没有入口依据的沉孔符号与单入口深度。不是按样本名、Ø70 或 90 常数特判。

用户已明确批准：仅删除 `test_corpus_regression.py::test_a_bore_flanched_by_smaller_bores_on_both_ends_is_not_a_counterbore` 的 4 行 strict xfail 装饰器。`needs_corpus`、函数、两条原断言全部保留。其余 109 份既有测试资产字节保持；新增文件含 42 个测试案例。例外不扩展到其他测试。

全量：**1116 passed，0 failed，0 skipped，185.97 秒**。前一版 1073 passed + 1 xfailed，本轮新增 42 项，原哨兵成为普通通过项。来源为 `full-regression-verified.log/xml`，冻结源码清单为 `release-candidate-hashes.json`。接入与保留核对见本文末尾及最终审计。

## 实现

1. `geometry/bore_topology.py` 从真实共享边确定圆柱与平面肩面的邻接；要求肩面另一侧连接更小的同轴内圆柱，并对应唯一有限端部。面枚举顺序不构成几何身份，哈希桶之后仍用 `IsSame` 核对。
2. 两端均有证据时标记内部扩腔；普通孔分组与相同直径/长度的盲孔分开，落位使用分组后的入口语义。物理孔、原值和来源保留。
3. 沉孔配对只产生候选。交付门逐一核验同组每个成员的底部肩面、局部入口、数量、直径及深度；缺证据或核验异常均 `refused/counterbore_semantics`，落盘前拦截，不回退到旧配对。
4. 入口以实测半径的解析圆柱和原实体求非破坏性交集；沿轴向只检查短邻域，长度为局部几何容差的 32 倍。容差取真实端圈相邻的面、边、顶点及圆柱自身，排除远处面与纵向接缝。该尺度属于数值分析，不是制造公差；本检查不声明全局加工可达性。
5. 三项派生字段 `shoulder_neighbors/topology_checked/end_tolerances` 排除在稳定问题身份之外；不改变未受影响问题的 ID。旧沉孔答案不能重绑定到修正后的普通直径问题。

两个只读审查角色分别核对几何/入口与服务/测试边界；主线程是唯一写者，真实 OCCT 检查串行。独立审查提出的角度判定、双端容差歧义、入口封闭以及非平面邻面容差问题均有对应实现和回归。
