## 实际行为

1. 唯一 `pipeline.render_part` 读取并冻结输入字节，从真实有限孔轴与STEP真实平面枚举候选。孔轴身份不依赖任取轴点、方向正负或拓扑顺序；量化仅用于身份，求交使用原精度。
2. 无默认选择。尚未确认时进入 `waiting_reference`，不生成DXF/SVG/PDF/JSON加工图。页面只展示源几何、孔轴、真实面片和选中交点；平面延拓明确标为“延拓平面参考，孔口关系未核实”。
3. 只接收当前快照的问题ID、候选ID或显式“不知道”。坐标、数值、向量及陌生字段拒绝；备注不参与计算。“不知道”返回 `reference_unconfirmed`，仍无图件。
4. 已选交点用于同一两向定位，并重新走所有原数值、来源、落位与纸面门。没有稳定候选、近乎平行、越出有限孔轴、身份碰撞、超过64项，以及当前两向策略不支持的方向/斜孔PCD均可解释地拒绝，不删除约束或猜参考。
5. 等待释放几何worker；持久化快照和独立确认记录。同一提交幂等，冲突不覆盖；恢复等待时重新检查来源，排队/运行中断沿用原中断规则。图后重算仍携带并重新验证同一参考。
6. 图面增加独立H/R注记、真实交点引注及当前基准坐标中的平面方程。共享平面显示常数按所有相关孔的最严格误差界限统一；未改变原生DIMENSION文字。仅带参考时JSON为schema4；普通schema2/3保持。
7. 人工CAD回传须保留带XDATA的关键参考注记及其显示/打印属性。关闭、冻结、不打印、透明、隐藏实体、改字形/字体或NOTE专属视口覆盖返回409，之前不建立版本或审图记录；正常保存及无关批注仍可回传。这是参考完整性保护，不是实际AutoCAD打印验收。

当前留存仍为人工核查/报告政策，超过200条仍保留；未增加自动删除。图前参考确认记录保存于任务，不冒充人工采用、制图签字或真实件统计。
