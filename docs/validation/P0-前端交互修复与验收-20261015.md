## 用户路径

1. 首次进入工作台，粘贴令牌，点击“连接服务”或按Enter；失败直接说明，成功后显示上传与历史任务。
2. 上传STEP/STP，或按文件名/任务号搜索、按状态筛选。新任务在前，当前任务有标记；新上传记录真实上传时间，旧任务没有时间则明确说明。
3. 待参考确认时，操作人前置。孔编号只切换查看对象，“预览参考面”只改变源几何显示，单选框才记录选择；可跳到下一未选孔或保存草稿稍后处理。
4. 生成图纸后，在图面上方下载当前预览的DXF/SVG/PDF/JSON，或直达复核。人工回传DXF与引擎图不同则明确提示，复核前需明确确认已下载并核对生效DXF。
5. 先选择复核结论，再核对零件、图纸版本、操作人、原因及说明摘要，最后点“确认提交复核”。取消不写审计；已勾问题不会被“直接用”清空。

## API与数据边界

- 新上传安全保存display_name/created_at/source_sha256，存储仍为服务端任务目录和model.step；客户端文件名不参与路径。
- 工作台使用GET /jobs?detail=1；任务使用GET /jobs/<id>?detail=1，取得显示元数据、来源/问题/参考/生效版本上下文与图前提交摘要。原端点默认响应形状保持，GET不写索引或审计。
- 浏览器复核必带reviewed_sha、reviewed_version、submission_id；服务端在同一版本/审计锁内核对当前图纸、冻结状态及提交身份。相同编号/相同内容返回原记录，内容变化409；重启后仍去重。
- 幂等身份使用完整认证指纹及席位名称；8位token_hint仅供既有审计显示。普通审核使用reviewed_*，不写代表CAD回传的effective_sha，避免污染试点统计。
- CAD版本发布、差异审计与普通审核共享锁顺序，避免新版本已生效而冻结审计尚未落下的间隙。
- 草稿仅属于当前标签页；同标签页刷新/任务切换可恢复，关闭标签页后不保证恢复。存储失败时提示并阻止丢稿导航及新复核写请求。

新增后端18项：名称安全/持久化、旧响应与只读元数据、来源变化、版本绑定、重复请求/新进程恢复、载荷冲突、非法输入零审计、短指纹碰撞、版本与冻结互斥。新增前端异步7项：跨任务历史缓存、迟到错误、旧会话列表、跨身份迟到复核、上传返回抢导航、存储失败阻止复核、旧下载401不影响新会话。测试执行实际前端函数，模拟延迟响应；不把这些单元场景称为浏览器验收。

真实浏览器在独立qa-*数据目录验证18项流程，故障注入仅在隔离客户端。模拟复核回包丢失后核对原记录，隔离服务共1条模拟复核，无重复POST。另有1次公开源文件副本的真实上传并出图；处理时返回列表可用。400/网络失败测试没有把参考答案发到主试点。390×844下无横向溢出，参考操作区不覆盖候选；1440×1000保留前后截图。

Safari另开隔离HTTPS标签页，原生检查连接、任务列表、图纸、下载入口及R键复核导航。证书保持现有仅SSL/127.0.0.1约束；没有新增信任或忽略TLS。检查后关闭隔离标签页，保留原8443页面及用户已选未上传文件。Ego任务空间59关闭，隔离HTTP/HTTPS服务均停止。
