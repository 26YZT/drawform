## 字体与内容

官方介绍：https://www.maoken.com/freefonts/14318.html 。标题用本地字库，运行时不依赖字体CDN；字体来源、版本、摘要、OFL和字库版权另随资源保存。原始字体若过大则以现有FontTools生成网页字集，保留许可与字形，不冒称完整字库或最新版。

可见品牌/标题/导航改为中文。「STEP / STP / DXF / SVG / PDF」等文件格式名称保留，实际接口路径、参数和技术标识不翻译。

主入口继续是已有模型转工程图。四功能块不是模拟操作，仍进入当前同源真实工作区。中文字体替换是用户明确授权的适配变更，原版5220与原参考manifest保留。
